# HEART.exe — Bubu Edition 💗

A responsive, multi-scene romantic sci-fi website built with plain HTML, CSS and JavaScript for GitHub Pages.

## What's included
- Dark cyberpunk neon-pink/purple UI and mobile responsive layout
- Bubu & Dudu GIF embeds from Tenor (internet connection required)
- Two funny fictional scans with joke text and a clear continue button after scan 2
- Memory galaxy with six clickable notes
- Three selectable universe themes
- Hidden-heart mini-game
- Secret message vault and surprise finale
- Optional browser-synthesized sci-fi ambience (off by default)
- Confetti celebration

## Preview locally
Extract the ZIP and open `index.html` in a modern browser. GIF embeds need an internet connection and may depend on the GIF provider's availability.

## Publish on GitHub Pages
1. Create a **Public** repository named `heart-exe-bubu`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` directly to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, branch `main`, folder `/(root)`, then **Save**.
5. Wait a few minutes and open the URL shown by GitHub Pages.

## Personalize
Edit `CONFIG` at the top of `script.js` to change the recipient and memory cards. Edit the letter text in `index.html`.

## Privacy and third-party embeds
GitHub Pages sites are public. Do not include private information or real passwords. The GIFs are embedded from Tenor and may contact that provider when loaded; their availability and behavior are controlled by Tenor.
